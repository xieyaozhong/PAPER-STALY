# Earth Science Sources

> 這是「來源索引」，不是授權保證。實際下載素材時仍以該檔案／dataset 當下的授權頁為準。

## 1. 地質／板塊／岩石

### USGS Multimedia Gallery
- URL: https://www.usgs.gov/products/multimedia-gallery
- 用途：地震、火山、岩石、地貌、水文、災害照片與動畫
- 建議：核心來源
- 授權：多數 USGS 原創作品為 Public Domain；逐項確認第三方例外

### FGDC Geologic Patterns for the Web
- URL: https://davenquinn.com/projects/geologic-patterns/
- GitHub: https://github.com/davenquinn/geologic-patterns
- 用途：地層柱、岩性填充、地質剖面、地質圖紋理
- 授權：CC0 / Public Domain foundation
- 建議：母素材庫必裝

### USGS Geologic Map Symbolization
- URL: https://pubs.usgs.gov/tm/2006/11A02/
- 用途：斷層、褶皺、位態、正式地質製圖標準
- 建議：地質圖判讀章節標準

### Macrostrat
- URL: https://macrostrat.org/
- 用途：全球地層、岩性、地質年代與地質圖服務
- 授權：依 Macrostrat 資料與服務條款標示，使用前確認 dataset metadata
- 建議：核心地質資料層

### GPlates
- URL: https://www.gplates.org/
- GitHub: https://github.com/GPlates/GPlates
- 用途：板塊重建、大陸漂移、地質年代動畫
- 軟體授權：GPL
- 注意：EarthByte / reconstruction datasets 各自確認授權

### Geoscience Australia
- URL: https://www.ga.gov.au/
- 用途：地質圖、岩性、斷層、DEM、製圖標準
- 授權：多數官方內容 CC BY 4.0，第三方例外需確認

### Smithsonian Open Access
- URL: https://www.si.edu/openaccess
- 用途：礦物、岩石、化石、隕石、博物館標本
- 授權：Open Access 標示素材大量使用 CC0；只下載明確 OA 項目

## 2. 地形／DEM／海底地形

### Natural Earth
- URL: https://www.naturalearthdata.com/
- 用途：世界海岸線、國界、河流、湖泊、城市、地形底圖
- 授權：Public Domain

### GEBCO
- URL: https://www.gebco.net/
- 用途：全球 bathymetry、海溝、洋脊、海盆
- 建議：海洋篇核心資料
- 注意：依當期 GEBCO Grid terms 保留建議 citation

### NOAA ETOPO
- URL: https://www.ncei.noaa.gov/products/etopo-global-relief-model
- 用途：全球陸地＋海底 relief、高程剖面、3D 地形
- 建議：全球 relief 核心

### OpenTopography
- URL: https://opentopography.org/
- 用途：SRTM、NASADEM、Copernicus DEM、ALOS、ArcticDEM、REMA 等
- 授權：聚合平台；每個 dataset 個別確認
- 狀態：YELLOW

### GeoMapApp / GMRT
- URL: https://www.geomapapp.org/
- 用途：海底地形、洋脊、海溝、海山、地球物理快速製圖
- 注意：GeoMapApp 與底層 dataset attribution 分開處理

## 3. 大氣／氣象／氣候

### NASA Scientific Visualization Studio
- URL: https://svs.gsfc.nasa.gov/
- 用途：氣候、大氣、洋流、冰層、衛星、地球、太陽、動畫
- 建議：科學視覺化核心
- 注意：逐項檢查 credit 與第三方素材

### Meteocons
- GitHub: https://github.com/basmilius/weather-icons
- 用途：晴雨、雲、雷暴、雪、霧、風等 UI 圖示
- 授權：MIT（以 repository 當期 LICENSE 為準）

### cmweather
- GitHub: https://github.com/openradar/cmweather
- 用途：氣象／雷達／降雨等科學 colormap
- 授權：MIT

## 4. 海洋

### NOAA Ocean Exploration
- URL: https://oceanexplorer.noaa.gov/
- 用途：深海、熱泉、海底火山、海山、ROV、海洋地質照片與影片
- 建議：海洋實景核心
- 注意：保留 caption credit；排除明確標示第三方 copyright 的素材

### NOAA Science On a Sphere
- URL: https://sos.noaa.gov/
- 用途：洋流、海溫、氣候、颱風、大氣、全球資料視覺化
- 授權：各 dataset 不同
- 狀態：YELLOW

### cmocean
- GitHub: https://github.com/matplotlib/cmocean
- 用途：海溫、鹽度、深度、密度、流速、異常值科學配色
- 授權：MIT

## 5. 衛星／遙測

### NASA Worldview
- URL: https://worldview.earthdata.nasa.gov/
- 用途：颱風、火災、雲、海冰、沙塵、降雨、衛星資料快速輸出
- 注意：輸出影像的底層 dataset attribution 要跟著保留

### Landsat
- URL: https://www.usgs.gov/landsat-missions
- 用途：長時間序列、都市擴張、海岸、植被、冰河、災害前後比較
- 建議：Before / After 教材核心

### Copernicus Sentinel-2
- URL: https://dataspace.copernicus.eu/
- 用途：10 m 級多光譜影像、真彩色／假彩色、NDVI、NDWI
- 注意：依 Copernicus data terms 使用與標註

### ESA WorldCover
- URL: https://esa-worldcover.org/
- 用途：10 m 全球土地覆蓋、森林、都市、農地、水體、濕地
- 授權：CC BY 4.0

## 6. 天文／行星

### NASA 3D Resources
- URL: https://science.nasa.gov/3d-resources/
- 用途：地球、月球、行星、探測器 3D model / texture
- 注意：依各素材頁 credit 與 NASA media rules

### ESA/Hubble
- URL: https://esahubble.org/images/
- 用途：星雲、恆星、銀河、黑洞、太陽系、exoplanet
- 授權：依站方 copyright / credit 規範，常見 CC BY 4.0

### ESO Image Archive
- URL: https://www.eso.org/public/images/
- 用途：深空、星雲、銀河、觀測天文
- 授權：依 ESO copyright / credit 規範

### USGS Astrogeology
- URL: https://www.usgs.gov/centers/astrogeology-science-center
- 用途：月球、火星、行星地質圖、DEM、正射影像
- 建議：行星地形核心

### OpenPlanetaryMap
- URL: https://openplanetarymap.org/
- 用途：月球／火星 web basemap 與互動地圖技術參考
- 授權：底圖來源不一
- 狀態：YELLOW

## 7. 台灣官方資料

### 地質雲 / 經濟部地質調查及礦業管理中心
- URL: https://www.geologycloud.tw/
- 用途：地層、活動斷層、液化、山崩、地熱、地質構造
- 建議：台灣地質主來源

### 中央氣象署 Open Data
- URL: https://opendata.cwa.gov.tw/
- 用途：氣象、雨量、地震、海嘯、觀測資料
- 建議：台灣大氣與地震主來源

### 國家海洋資料庫 NODASS
- URL: https://nodass.namr.gov.tw/
- 用途：海洋水文、生態、波浪、海域觀測與相關開放資料
- 注意：逐 dataset 查看授權與使用條件

### 政府資料開放平台 — 全臺灣 DTM
- URL: https://data.gov.tw/
- 用途：台灣高程、Hillshade、Contour、Slope、Aspect、地形剖面
- 授權：依資料集標示；常見政府資料開放授權條款第 1 版

### 國土測繪中心 NLSC
- URL: https://www.nlsc.gov.tw/
- 用途：地形、圖磚、WMS / WMTS、部分 LiDAR / DEM 資料
- 注意：依服務與資料集個別條款

### TASA 福衛影像
- URL: https://www.tasa.org.tw/
- 用途：台灣本土衛星案例與影像
- 狀態：YELLOW，逐項確認授權後再納入母素材庫

## 不直接進商業母素材庫

- PhET simulations：適合課堂展示，但部分現行模擬授權含 NonCommercial 條件
- OpenStax Astronomy 2e：現行授權含 NC 條件時，不作商業母素材直接重用
- Wikimedia Commons：只作補洞來源，每個檔案逐張檢查授權
- EarthScope 教育素材：非常適合教學，但需逐項確認再打包重用
