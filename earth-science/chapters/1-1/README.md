# 1-1 地球的起源與演變｜Asset Pack

本章依南一版章節架構整理，但內容、圖解與題目皆重新編寫，不直接複製教材內容。

## 教學主線

> 星雲收縮 → 原行星盤 → 行星吸積 → 地球分異 → 月球形成 → 大氣與海洋

記憶句：

> **重力聚集、溫度選材、吸積長大、密度分層、冷卻成海。**

## 視覺方向

- NASA scientific mission / Earth Observatory 感
- A4 學生講義優先
- 高對比黑／白／灰＋科學資料色階
- 圖示統一單色、固定線寬
- 不使用 emoji、3D 貼圖或混搭卡通 icon
- 照片只在本身具有科學資訊時使用
- NASA 僅作科學視覺語言與公開資料來源參考，不使用 NASA Logo 作為教材品牌
