# Waves & Optics Starter Pack

第二批可直接用於物理講義的自製 SVG 素材。

## 核心主題

1. 波的基本量：振幅、波長、週期、頻率
2. 疊加原理
3. 駐波與節點／腹點
4. 都卜勒效應
5. 反射定律
6. 折射與法線
7. 凸透鏡成像光線圖
8. 雙狹縫／波動干涉概念

## 視覺語意

- 波峰／光線／傳播方向：青色 `#56d7e8`
- 幾何角度／重點條件：橘色 `#ff9f1c`
- 法線／平衡位置／輔助線：灰色 `#66717f`
- 圖像為教學示意，非按真實尺度。
