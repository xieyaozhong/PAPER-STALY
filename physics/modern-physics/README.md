# Modern Physics Starter Pack

本素材包延續 `physics/VISUAL_SYSTEM.md` 的物理教材視覺語言，以 **橘色＝能量／光子／高能事件、青色＝波／場／量測／軌跡** 為核心語意。

## 已完成素材

1. `01_photoelectric-effect.svg` — 光電效應
2. `02_de-broglie-wave.svg` — 德布羅意物質波
3. `03_atomic-energy-levels.svg` — 原子能階與躍遷
4. `04_emission-spectrum.svg` — 發射光譜
5. `05_radioactive-decay.svg` — 放射性衰變曲線
6. `06_half-life.svg` — 半衰期
7. `07_mass-energy.svg` — 質能互換
8. `08_nuclear-fission.svg` — 核分裂
9. `09_nuclear-fusion.svg` — 核融合
10. `10_particle-collision.svg` — 粒子碰撞與徑跡
11. `11_gravitational-wave.svg` — 重力波 strain 波形

## 使用方式

- 講義：直接嵌入 SVG，可在排版軟體中保留向量品質。
- 網頁：可直接 `<img>` 或 inline SVG。
- 動畫：後續可用 Manim / JavaScript 將箭頭、波形、粒子徑跡動畫化。
- 真實資料：重力波可替換為 GWOSC 公開資料；粒子碰撞可替換為 CERN Open Data 衍生圖。

## 科學標示原則

- `DIAGRAM`：教學概念示意，不代表真實尺度。
- `MODEL`：物理模型結果或理論預測。
- `OBSERVATION`：由真實儀器／資料重繪。
- 真實 CERN / GWOSC 資料進入教材時需在 attribution 表補齊來源。
