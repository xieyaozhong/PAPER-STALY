# Electricity & Magnetism Starter Pack

本素材包提供高中物理電磁學章節可直接使用的原創 SVG 圖解，沿用 PAPER-STALY 物理視覺系統。

## 已完成

1. `01_coulomb-law.svg` — 庫侖力
2. `02_electric-field-lines.svg` — 電場線
3. `03_equipotential.svg` — 等位面／等位線
4. `04_series-parallel.svg` — 串聯與並聯電路
5. `05_kirchhoff.svg` — Kirchhoff 接點與迴路
6. `06_capacitor.svg` — 平行板電容器
7. `07_bar-magnet-field.svg` — 條形磁鐵磁場
8. `08_wire-magnetic-field.svg` — 載流導線周圍磁場
9. `09_lorentz-force.svg` — 洛倫茲力方向
10. `10_faraday-induction.svg` — 法拉第電磁感應

## 視覺規則

- 深色背景
- 橘色：力／正電／能量輸入／變化來源
- 青色：場／運動方向／量測／負電
- 白色：幾何結構與主文字
- 向量與場線盡量使用箭頭，避免只靠顏色表意
- 所有圖均為概念示意，若非真比例需標示 `NOT TO SCALE`
