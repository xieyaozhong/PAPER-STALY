# Mechanics Starter Pack

物理素材庫第一個可直接製作講義的章節包。

## 核心主題

1. 牛頓第二定律
2. 自由體圖
3. 斜面受力
4. 拋體運動
5. 等速圓周運動
6. 動量與碰撞
7. 動能／位能轉換
8. 胡克定律與彈簧
9. 槓桿與力矩
10. 滑輪與機械利益

## 視覺規則

- 深色科學底：`#0b0d10`
- 力／加速度：橘色 `#ff9f1c`
- 速度／位移／軌跡：青色 `#56d7e8`
- 輔助線：灰色 `#66717f`
- 重要物體：淺灰／白
- 所有向量箭頭均直接標量名與方向
- 圖像預設為概念示意；若比例不精確要標註 `not to scale`
