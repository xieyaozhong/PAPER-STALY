# Measurement & Experimental Physics Starter Pack

這一包用於物理實驗、資料判讀與科學測量相關講義。

## 已完成素材

1. `01_si-units.svg` — SI 基本量與單位
2. `02_dimensional-analysis.svg` — 量綱分析／單位檢查
3. `03_accuracy-precision.svg` — 準確度與精密度
4. `04_measurement-uncertainty.svg` — 測量值與不確定度
5. `05_repeated-measurements.svg` — 重複量測與平均值／誤差棒
6. `06_linear-fit.svg` — 線性擬合、斜率與截距
7. `07_vector-components.svg` — 向量分解
8. `08_experiment-workflow.svg` — 實驗資料流程

## 視覺語意

- 橘色：理論值／基準／主要量
- 青色：量測值／資料／向量分量
- 灰色：不確定區間／背景參考

## 使用方式

- 實驗講義
- 科學方法與測量章節
- 圖表判讀題
- Tracker / 感測器資料分析
- 大考素養題中的誤差與線性關係題
