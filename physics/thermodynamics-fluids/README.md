4. `04_pv-diagram.svg` — P–V 圖與氣體作功
5. `05_hydrostatic-pressure.svg` — 液體靜壓
6. `06_pascal-hydraulics.svg` — 帕斯卡原理與液壓
7. `07_buoyancy.svg` — 浮力與阿基米德原理
8. `08_bernoulli-venturi.svg` — 連續方程與伯努力效應
