# Physics Visual System

物理圖解的核心不是「好看」，而是讓向量方向、物理量、因果關係與測量意義保持一致。

## 1. 共用視覺語言

延續 PAPER-STALY 現有科學教材風格：

- 深色背景：`#08111C`
- 主文字：`#F7FBFF`
- 輔助文字：`#8EA6B8`
- Cyan：`#66D9FF`
- Orange：`#FF9D36`
- 結構線：`#71808C`

## 2. 顏色語意

### Cyan
優先表示：
- 運動方向
- 速度／加速度向量
- 支持力／外加控制量
- 電場／磁場的主要視覺線
- 冷端／低能量（只有在熱學圖中）

### Orange
優先表示：
- 重力
- 阻力／摩擦
- 熱／高溫
- 能量輸入／碰撞
- 正電荷
- 警告與常見迷思

> 顏色不是物理定律。同一張圖內的語意要一致，跨章節則以標籤優先於顏色。

## 3. 向量規範

- 箭頭起點應盡量落在「作用物／位置」上。
- 力向量標籤使用 `F`, `N`, `mg`, `T`, `f` 等標準符號。
- 速度使用 `v`，加速度使用 `a`。
- 電場使用 `E`，磁場使用 `B`。
- 同一幅圖中的向量長度只有在明確標註時才代表大小比例。
- 若箭頭不按比例，圖說加入 `schematic / not to scale`。

## 4. 圖解類型標籤

每張物理圖可使用以下標籤之一：

- `OBSERVATION` — 實驗或感測器直接量測
- `DATA` — 真實資料圖表
- `MODEL` — 數值／物理模型
- `SIMULATION` — 可操作模擬
- `DIAGRAM` — 教學概念示意
- `FREE-BODY` — 自由體圖
- `CIRCUIT` — 電路圖
- `RAY` — 光路圖

## 5. 坐標系

- x 軸預設向右、y 軸預設向上。
- 若採非標準座標，必須畫出座標軸。
- 斜面問題建議另畫沿斜面／垂直斜面的局部座標。
- 正負號先依座標系定義，不依「向上一定正」等記憶規則。

## 6. 力學

- 自由體圖只保留作用在選定物體上的外力。
- 不把「運動方向」畫成力。
- 牛頓第三定律作用力與反作用力必須畫在不同物體上。
- 摩擦方向由相對運動／趨勢判定，不固定向左或向右。

## 7. 波動

- 明確區分「介質質點運動方向」與「波的傳播方向」。
- 波長標示同相位點間距。
- 振幅由平衡位置量起，不從波峰量到波谷。
- 聲波若畫成正弦圖，應標記那是物理量對位置／時間的圖，不是空氣真的呈現波浪形。

## 8. 光學

- 入射角、反射角、折射角皆從法線量起。
- 光路箭頭必須標方向。
- 透鏡／面鏡圖若不按比例，標示 schematic。
- 實像／虛像用一致的實線／虛線規則。

## 9. 電學與磁學

- 傳統電流方向與電子漂移方向要分開標示。
- 電場線由正到負；場線不是真實物體。
- 磁場線形成閉合曲線。
- 電路圖優先使用標準 circuit symbols，不用擬物電池／燈泡取代正式電路圖。

## 10. 熱學與流體

- 溫度 ≠ 熱量。
- 熱流方向依溫度差表示。
- 壓力箭頭應垂直於表面。
- 浮力方向與液體壓力分布要分開表現。

## 11. 輸出規格

### 講義
- SVG 優先
- A4 raster 最低 300 dpi
- 線寬縮小到教材尺寸後仍需可辨識

### Web
- SVG / Canvas / WebGL
- 文字與互動控制需有足夠 contrast
- 模擬需可暫停、重設，最好能顯示數值

## 12. 素材命名

```text
PHY_<topic>_<concept>_<variant>_v01.svg
```

例如：

```text
PHY_mechanics_free-body_horizontal_v01.svg
PHY_waves_wavelength-amplitude_v01.svg
PHY_optics_reflection-refraction_v01.svg
PHY_electricity_series-circuit_v01.svg
```
