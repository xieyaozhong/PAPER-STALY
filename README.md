# PAPER-STALY

教材與科學視覺素材整理庫。

目前先建立 **Earth Science Open Asset System**，集中管理地球科學教材可使用的開放素材來源、授權規則、素材清單與後續下載／加工規格。

## Earth Science

入口：[`earth-science/README.md`](earth-science/README.md)

目前涵蓋：

- 地質與板塊構造
- 地震與火山
- 地形／DEM／海底地形
- 大氣與氣象
- 海洋
- 衛星遙測
- 天文與行星
- 科學配色與地圖符號
- 2D／3D 互動地圖工具
- 台灣官方開放資料

## 原則

1. 優先使用 Public Domain、CC0、MIT、BSD、Apache、CC BY 等可重用來源。
2. 所有素材保留來源、作者／機構、授權與下載日期。
3. 第三方或授權不明素材不直接納入商業教材母素材庫。
4. 原始科學資料與輸出教材圖分離保存，方便重製與更新。
5. 不直接鏡像大量第三方檔案；先建立 manifest，再逐章精選下載。
