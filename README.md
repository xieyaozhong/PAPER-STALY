# PAPER-STALY

教材與科學視覺素材整理庫。

目前已建立兩套可持續擴充的素材系統：

- **Earth Science Open Asset System**
- **Physics Open Asset System**

兩者都集中管理教材可使用的開放素材來源、授權規則、素材 manifest，以及後續下載／加工規格。

## 原則

1. 優先使用 Public Domain、CC0、MIT、BSD、Apache、CC BY 等可重用來源。
2. 所有素材保留來源、作者／機構、授權與下載日期。
3. 第三方或授權不明素材不直接納入商業教材母素材庫。
4. 原始科學資料與輸出教材圖分離保存，方便重製與更新。
5. 不直接鏡像大量第三方檔案；先建立 manifest，再逐章精選下載。
6. GPL / LGPL 等開源程式可以使用，但散布與修改時必須遵守其相應條款。
